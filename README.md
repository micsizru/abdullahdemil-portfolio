# Abdullah Demil - Portfolio & CV

A CV website of mine because i couldn't find a good CV template online. Also this is a good simple project to practice my HTML and CSS skills after a long time.

## Structure
- `index.html`: Turkish CV
- `ru.html`: Russian CV
- `assets/css/`: Stylesheets
- `assets/images/`: Profile photo and icons

## Usage
Open `index.html` or `ru.html` in any modern browser. To export as PDF, use the browser's print function (`Ctrl+P`) and select "Save as PDF"
